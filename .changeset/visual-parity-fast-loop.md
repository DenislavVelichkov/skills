Visual parity converges before the human gate. The protocol template adds a draft loop with an independent pre-request review that returns every finding in one pass, one proof run per approval request, capture lanes with an off-lane preflight, byte-stable captures, complete rejections and batched approval requests. `to-tickets` blocks a surface ticket only on a technical prerequisite instead of chaining surfaces in manifest order. A draft loop still open after its third review stops and goes to the human as a blocker, and each surface reports its approval cycles, draft-loop reviews, lane holds and elapsed time when it closes. The validator accepts `--print-request` for several surfaces, lists changed frames with `--changed-since` from the manifests' recorded digests alone, and checks an optional `preRequestReview` record. A manifest policy can require that record and the request's `attempt` on every surface whose approval was requested; `preRequestReviewFrom` exempts requests made before a manifest adopted the policy. Each closing record uses one measurements table.
