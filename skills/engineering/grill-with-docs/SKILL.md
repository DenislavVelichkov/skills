Before the first question, call the Skill tool twice, for "grilling" and "domain-modeling". If either is unavailable, report it and stop; do not improvise.

Use `grilling` for the question rounds and `domain-modeling` to record resolved terms and qualifying ADRs as they arise, under its lazy file creation rules.

At the end, report the paths of the `GLOSSARY.md` and ADR files created or changed. If no term or ADR qualified, say so.
