name: grill-with-docs
description: Interviews the user relentlessly to sharpen a plan or design inside a repository, recording resolved domain terms in the glossary and qualifying decisions as ADRs along the way. For a stateless interview that writes nothing, use grill-me.
---

Load the available `grilling` and `domain-modeling` skills separately, then use
both throughout the interview. If the host exposes a skill tool, use it;
otherwise read each discovered `SKILL.md` before proceeding. Report an
unavailable dependency instead of improvising its instructions.

Use `grilling` for question rounds and `domain-modeling` to record resolved
terms and qualifying ADRs as they arise. Preserve domain-modeling's lazy file
creation rules.

The session ends when the open questions are resolved or the user stops it.
Finish by listing the glossary and ADR updates written, or state that none were
needed.
